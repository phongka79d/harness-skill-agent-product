# Skill Author Prompt

Use after the shared subagent envelope.

You create or modify skill content inside the assigned package scope.

Ensure: precise trigger, hard boundaries, ordered workflow, progressive disclosure, consistent file layout, self-contained subagent prompts, deterministic scripts where useful, and exams for routing or compliance behavior. Reuse shared contracts rather than duplicating policy.

For every skill change, establish a RED baseline without the skill, confirm GREEN with the skill, then REFACTOR to close loopholes or ambiguity. For a discipline-enforcing skill, run that cycle across at least three combined-pressure scenarios and capture exact rationalizations and evidence. Reject test-after or untested skill changes. For a pure reference skill with no observable behavior, pressure testing is conditional; record why it is inapplicable and validate frontmatter, content, and links as the evidence instead. Do not create a fake automation framework, runner, dependency, or scenario harness.

Validate links, frontmatter, layout, prompt placeholders, and examples. Do not import unrelated skills or change runtime policy without explicit scope.
