# Planning Workflow

1. Clarify the request and record the approved architecture and constraints.
2. Create versioned plans and atomic task contracts in the project documentation area.
3. Resolve the project profile and deterministic rubric.
4. Validate schemas, dependencies, scope overlap, approvals, and handoffs.
5. Obtain the required approval before execution.

Plan changes create a new version and an immutable supersede link. Historical plan evidence is never edited in place.
