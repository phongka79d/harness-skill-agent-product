# Claim-to-evidence mapping

Assign each acceptance criterion a stable ID. Use that exact ID as the corresponding `verification.json` check name and `completion-claim.json` acceptance ID.

The two ID sets must be unique and equal. A claim cannot add an unverified criterion or omit a verification check. Map each ID to direct observations, commands, or inspections; a generic statement such as “looks good” cannot satisfy a concrete criterion.
