# Universal handoff template

Use these labels exactly, in this order. Every field is required; an empty field must say `NONE` rather than introducing a different label.

STATUS: PASS | CHANGES_MADE | REPAIR_REQUIRED | BLOCKED
SUMMARY:
FILES_READ:
FILES_CHANGED:
EVIDENCE:
FINDINGS_OR_IMPLEMENTATION:
RISKS:
OPEN_QUESTIONS:
NEXT_STEP:

`FINDINGS_OR_IMPLEMENTATION` carries the bounded implementation or findings. `EVIDENCE` carries commands, outputs, observations, and test-first results. The Primary Agent/host may persist a handoff artifact; the Implementer does not write `.phongka` state directly.
